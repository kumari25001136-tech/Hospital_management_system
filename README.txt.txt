# Hospital Management System

## Project Overview
A MySQL-based Hospital Management System designed to manage hospital operations and patient information.

## Database Tables
1. Department
2. Doctor
3. Room
4. Patient
5. Admission
6. Appointment
7. Medical_Record
8. Prescription
9. Bill

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

## Project Files
- Hospital_Management.sql – SQL script
- Hospital_Management_Backup.sql – Database backup

## Features
- Manage patient records
- Manage doctors and departments
- Track appointments and admissions
- Maintain medical records and prescriptions
- Manage hospital bills

## How to Use
Open the SQL file in MySQL Workbench and execute it on a fresh database to create the tables and insert sample data.
